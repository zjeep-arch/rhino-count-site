Meta不开源了：Llama的旗手，举起了收费牌

2026年10月18日 · 约2300字
信源：英国《金融时报》、路透社、Meta Connect 大会及扎克伯格访谈

撰文｜犀牛伯爵

核心判断

Meta 不开源，不是掉队，是补入场券。北美头部模型没有一家开源，付费习惯已经养成，闭源才是主流玩法。真正的牌在另一边：Muse 两周数百万用户登顶下载榜，700 万副眼镜等着装上它。模型是大脑，眼镜是身体，Meta 第一次把 Agent 的"身体"和"大脑"凑齐，往后靠交易抽佣赚钱。

01

收费牌：20 美分和 200 美元

10 月 12 日，Meta 发布了 Muse Wonder 和 Muse Wonder Full 两款模型。扎克伯格对《金融时报》说，Meta 已经在 AI 的"前沿领域"追上竞争对手，部分基准测试超过了 Anthropic 的 Claude Opus 5.5 和 OpenAI 的 GPT-6 Astra。

但比"追上"更值得看的，是"不开源"。Llama 时代，Meta 是开源阵营的旗手。这一次，Muse Wonder 明确走闭源路线，用户和公司都要付费才能用。

价格已经摆出来了。基础版每百万 token 低至 20 美分，功能更强的 Wonder Full 走订阅，月费 50 到 200 美元。API 的价格，Meta 说比 OpenAI 和 Anthropic 的主力模型"大幅要低"。

Meta 的算盘不难拆。过去一年，扎克伯格投了数十亿美元，重组 AI 团队、建数据中心、开数百万美元年薪挖顶尖研究员。这笔钱不能只换一篇论文，必须换回收入。广告之外，Meta 需要第二条赚钱的路。

互动 · 这套定价在打谁

20 美分 / 百万 token

打的是开发者的算账心态。Meta 宣称比 OpenAI 和 Anthropic 的主力模型"大幅要低"——先用价格把调用量抢过来，再谈别的。

$50 – $200 / 月

打的是重度用户和企业的钱包。Wonder Full 定位旗舰，订阅制锁定高价值用户，顺带给 Muse 应用导流。

先免费 再收钱

中间留了一档免费额度，先把人圈进来。Muse 上线两周用户数百万、登顶美区下载榜，流量入口已经备好。

这不是技术发布，这是一份价目表。

02

入场券：北美头部，没有一家开源

有人会问，Meta 当年举开源大旗，如今改闭源，算不算认输？恰恰相反，这是在补入场券。

扎克伯格自己也把路线说清楚了。OpenAI 和 Anthropic 要做通用人工智能，Meta 要做"个人超级智能"，给普通人用的 AI 助手。两条路线，收钱的方式都一样：订阅加 API。

最强的模型，没有一家开源。客户已经被教育出来了，为好模型付费是天经地义的事。

Llama 时代 Meta 是开源旗手，赢得了开发者口碑。但口碑换不回数十亿美元的投入，开源谈的不是生意。

继续只谈开源，谈的就不是生意，是情怀。北美头部全员闭源收费，Meta 不跟进，等于把"个人超级智能"的入场券让给别人。

开源还是闭源，从来不是信仰问题，是账本问题。

03

身体：700 万副眼镜等着装上它

模型是大脑，Agent 需要身体。Meta 的身体早就备好了，藏在眼镜里。

9 月 25 日的一档访谈里，扎克伯格宣布，Muse 将整合进全线 Ray-Ban 智能眼镜。用户不用再喊"嘿 Meta"，自定义一个唤醒词，直接叫出自己的个人 Agent。他说，多年来被外界看作三场独立豪赌的元宇宙、智能眼镜和大模型，正在产品层面完成交汇。

扎克伯格有一句很关键的话：眼镜是"唯一能让你的 Muse 看到你所见、听到你所闻的形态"。手机是口袋里的，电脑是桌上的，眼镜是脸上的。OpenAI 和 Anthropic 有大脑，没有身体，这就是 Meta 手里独一无二的牌。

04

怎么赚钱：从交易里抽佣

订阅和 API 是第一步，更大的钱在后面。扎克伯格在 Connect 大会上透露，未来 Meta 会从 Muse 经手的交易里抽取"一小笔佣金"。

想想 Muse 能干什么：订餐厅、订行程、买杂货。Agent 每替用户完成一笔消费，Meta 就从中切一刀。这是从"卖广告"到"抽交易税"的转身——苹果靠 App Store 抽佣吃到了软件时代最大的红利，Meta 想在 Agent 时代复制一遍。

为此 Meta 配了全套基础设施。每个 Muse 背后都有一台专属的安全虚拟机，用户数据加密存放，敏感凭证独立管理，还有一个叫 Sentinel 的安全 Agent 专门盯着数据流。Agent 要经手真金白银，信任就是地基。

05

别急着开香槟

降温的话照例说在前面。发布当天就出了 bug：Meta Code 订阅服务对 Wonder 调用额度的统计出了漏洞，首席 AI 官 Alexandr Wang 在 X 上承认"还有不少漏洞正在排查"。追上了模型，没追上工程细节。

第二，"追上"是自家基准说的。第三方独立评测还没大规模跟上，榜单是 Meta 自己画的。Llama 4 的失败扎克伯格自己都承认是"最可怕的时刻"。新团队的第一份答卷，需要第三方验票。

第三，眼镜这条线有隐忧。加州已经有集体诉讼指控 Meta 在隐私保护上误导用户，英国多家餐厅酒吧开始限制顾客佩戴智能眼镜。身体有了，社会能不能接受这个身体，是另一道题。

点开展开 · 三个降温项

Meta Code 订阅对 Wonder 调用额度的统计出漏洞，Alexandr Wang 在 X 上承认"还有不少漏洞正在排查"。模型分数可以靠砸钱追，工程细节靠的是组织能力——而这正是 Llama 4 翻车的原因。
超过 Claude Opus 5.5 和 GPT-6 Astra 的说法来自 Meta 自己的基准测试。第三方独立评测还没大规模跟上，在验票之前，"追上"先打个问号。

证伪条件 · 犀牛判断留档

未来两个季度，如果 Muse 的订阅收入和企业 API 调用量没有起量，或者眼镜销量增速放缓，"身体加大脑"的故事就降级为"又一个硬件梦"。反过来，如果交易抽佣真的跑通，Meta 就找到了广告之外的第二条命。
