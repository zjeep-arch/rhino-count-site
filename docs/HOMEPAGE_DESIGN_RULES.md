# 首页视觉与内容规则

首页采用「动态编辑杂志 × 数字档案室」视觉方向：深墨绿为主，暖纸白用于 NOW、Picks 和宣言形成明暗跨页，青绿作为品牌色，朱砂用于少量重点，电光钴蓝只作局部对冲色。每个板块可有独立的纸张、软盘、印刷海报或作品展台材质，但共享编号、细线、纸纹和微光语言。Profile 文件夹与 Signals 软盘作为特色交互保留。不要把所有板块都做成满屏动画。

- 首屏必须有且仅有一个 h1，明确个人定位，并直接通向观察与作品。个人履历以 data.js 已确认内容为准，不增加未经核实的规模、客户或成就。
- homepage-editorial.js 是首屏、Signals 阅读卡和日报的共用渲染器。发布前运行 scripts/render-editorial.mjs 保持静态与运行时一致。
- 首页提供 3 个正常字号的观察入口；软盘效果不能成为唯一阅读方式。标题与链接必须对应，不把作者主页包装成具体文章。
- 日报最新入口使用 ai-daily/feed.json 的 url 字段，按 slug 排序；静态构建也读取 feed。失败时提供档案入口，不显示编造的最新标题。
- NOW 为简短观点摘要，日报只保留一套标题与说明。正文不使用 Impact 字体或霓虹渐变文字；全页不添加电影黑边、背景粒子或自动弹出的吉祥物提示。
- 吉祥物只保留为页尾互动。Profile 动画遵守减少动态效果设置，并在离开视口时暂停。
- 检查 1440、1024、390 宽度，确认无横向溢出、菜单和筛选可用、身份顺序不变、Builds 项目不受文章更新影响。
- 本轮验收不代表文章事实或第三方订阅投递系统已审核。对外内容仍需独立核实。

- 首屏右侧使用静音循环动态视频，保留静态首帧；尊重系统的减少动态效果设置。联系入口使用小红书，不恢复邮箱订阅区。

- 颜色角色固定：深墨绿承载 Profile、Signals、Builds 与日报；暖纸白用于 NOW、Picks 与宣言；青绿作为全站品牌色，朱砂作为材质暖色，电光钴蓝只用于封面、刻度和选中态，灰蓝与赭金用于 Builds 类别识别。内容卡片可以有原创 CSS/矢量感封面，不引用无关图片；动效使用入场、局部视差、指针柔光和明确的点击状态，尊重减少动态效果设置；不得遮挡内容或破坏 Builds 卡片布局。

- 宣言区采用纸本专题版式：保留完整原文、固定标题顺序，工作步骤支持鼠标悬停、键盘焦点和点击选择；刻度装饰随所选步骤变化。小屏自然换行，减少动态效果设置下仍可操作。

- 首屏视频边缘和色调需融入暗色背景，保持人物清晰；标题与导航可使用指针逐字微光，文字内容、换行、无障碍名称与减少动态效果设置必须保留。

- `scripts/render-editorial.mjs` 在 Node `vm` 中预渲染 `RhinoEditorial`；渲染函数必须是纯函数，只返回静态标记。定时器、DOM 查询及其他浏览器行为放在单独的浏览器脚本中。PR 校验和部署前均运行完整静态构建检查。

- 日报默认以紧凑封面卡呈现最新一期；北美 AI 活动放入原生 details/summary 抽屉，默认收起，键盘与触屏均可展开。日报整体外框沿用全站版心，内部可使用两栏和窄栏，但从共享网格线起排；移动端使用纵向封面与轻量留白。

- 日报封面图形必须裁切在独立缩略框内，并与标题摘要建立明确层级；标题不重复展示已单独呈现的日期，避免长标题挤压封面排版。

- 日报封面只保留一个图形刊头，缩略图裁切在左侧独立框内；右侧标题以简短的一行主标题呈现，日期放在眉题。左侧引言用分段入场和轻量悬停位移增强节奏，尊重减少动态效果设置。

- 全站内容共享单一版心：桌面最大宽度 1240px，左右内边距随视口平滑缩放；导航、首屏文案索引、普通板块、日报、宣言和页脚使用相同边界。特殊视觉可以满版出血，窄栏可以留存，但必须锚定共享网格，不能通过独立居中或局部 max-width 偏移。手机端共用安全边距，所有区块按同一左边线纵向阅读。

- Picks 双列卡片在桌面端统一标题行高（宽屏两行位、中等桌面三行位）、作者占一行、简介保持三行栏位，底部时长/来源对齐；窄屏单列取消预留空行，按自然内容流排版，简介最多两行。
