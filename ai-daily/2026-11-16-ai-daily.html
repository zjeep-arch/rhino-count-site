>> 九、AI 安全洞察

开源 Agent 模型逼近闭源旗舰，能力扩散快于治理准备

本期证据：LongCat-2.5 以 MIT 协议开源，Terminal-Bench v2.1 88.4 分，仅比 Claude Opus 5 低 0.7 分；阿里 Qwen4-Max 与百度文心 5.5 Flash 同日上新，国产旗舰上新节奏压缩到「同日对撞」。

趋势建议：把开源 Agent 模型纳入与闭源同等的部署前红队与运行期监测，别只看参数量与许可证，部署方要自己补上使用边界与审计。

智能体 commerce 协议栈正在成型：身份握手与支付同日补齐

本期证据：Sierra Poppy 1.0 规范智能体如何代表用户与商家交互，Shopify 全量启用、Meta Muse 优先查找；同日 OpenAI 推出 ChatGPT Wallet，智能体可在授权下代用户结账。

趋势建议：把支付授权与身份授权分开管，给智能体钱包设单笔限额与逐笔确认，账单追溯要能对应到具体任务与授权人。

云厂商 AI 安全：评测等级正在变成采购语言

本期证据：华为云智果 AgentArts 成为首个通过信通院可信 AI 评估并获 4+ 级的智能体平台；绿盟方案入选 IDC 企业级智能体安全报告；微软 Dynamic Permissions 把权限做成任务级、可随风险动态收紧。

趋势建议：选型时把评测等级、检出率与误报率写进合同验收条款，别用一张功能清单代替整套护栏。

权重指纹让训练硬件变得可审计，合规从「信厂商说的」变成「可技术验证的」

本期证据：Will DePue 的权重指纹分析称六款中国开源模型带有 Blackwell 硬件特征，方法本身不证明违规或位置；德国联邦议院同周首议 AI 安全动议案，要求强化评测与监管。

趋势建议：采购与合作前核查模型训练硬件谱系与出口管制暴露，合同里留出管制变化的退出与替代条款。

开发工具链成为新的攻击面，供应商密钥与扩展市场要进供应链清单

本期证据：Cursor 事件源头是发给推理供应商 Fireworks 的密钥泄露，攻击者进而篡改扩展分发缓存，至多 5000 名用户可能收到带 SSH 后门的 Claude Code 扩展；更新扩展本身清除不了后门。

趋势建议：把推理供应商密钥、扩展市场与构建缓存纳入供应链清单，开发机装扩展走允许清单与版本锁定，密钥泄露要按「已泄露」处置、别等利用证据。
